评估口径与范围

  • 配对口径：同一水库、同一天同时有预报与实测才算一个对照日，缺一项不参与。
  • 绝对偏差 = 预报 − 实测（m³/s），正数为偏大、负数为偏小；相对偏差 = 绝对偏差 ÷ 实测 × 100%。
  • 按量加权平均绝对相对偏差：以各日实测流量为权重，对相对偏差加权平均（实测为 0 的日子不参与相对偏差口径）。
  • 命中（落在允许范围）：|相对偏差| ≤ 当前允许范围；实测为 0 时要求预报也为 0 才算命中。当前判定范围写在下方评估卡上。
